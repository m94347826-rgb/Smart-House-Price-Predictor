# Smart House Price Predictor 🏠

This project is a practical application of the concepts and certifications I earned in Artificial Intelligence and Machine Learning engineering.

## Overview
A complete machine learning project that follows the full data science lifecycle, from data processing to training a Linear Regression model to estimate house prices based on features like area, bedrooms, and bathrooms.

## Key Features
- Instant and accurate house price predictions.
- Trained machine learning model saved and loaded using Joblib (`house_model.pkl`).
- Clean, structured, and professional project architecture.

## Tech Stack
- **Python**: Core programming language.
- **Scikit-Learn**: Machine learning algorithms (Linear Regression).
- **Pandas & NumPy**: Data manipulation and processing.
- **Joblib**: Model persistence and deployment.
