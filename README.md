# Smart House Price Predictor 🏠

This project represents a practical application of the concepts and certifications I obtained in artificial intelligence and machine learning engineering.

## Overview
A complete machine learning project that follows the full data science lifecycle, starting from data processing to training a linear regression model to estimate house prices based on features like area, bedrooms, and bathrooms.

## Key Features
- Instant and accurate house price predictions.
- Trained machine learning model saved and loaded (`house_model.pkl` using Joblib).
- Clean, structured, and professional project architecture.

## Tech Stack
- **Python**: Core programming language.
- **Scikit-Learn**: Machine learning algorithms.
