# Smart House Price Predictor 🏠

A machine learning project designed to estimate house prices based on features such as area, bedrooms, and bathrooms. Developed using Python, scikit-learn, and Joblib.

## Overview
This project follows the complete data science lifecycle, from data preprocessing and linear regression modeling to model persistence and saving (`house_model.pkl`).

## Key Features
- Instant and accurate house price predictions.
- Clean and structured project architecture.
- Trained machine learning model saved and loaded efficiently using Joblib.

## Tech Stack
- **Python**: Core programming language.
- **Scikit-Learn**: Machine learning algorithms (Linear Regression).
- **Pandas & NumPy**: Data manipulation and processing.
- **Joblib**: Model persistence.
